# 📌 Sticky Notes Board — Interactive Digital Corkboard

A lightweight, interactive, and customizable digital sticky notes corkboard built with vanilla HTML, CSS, and JavaScript.

Drag, customize, pin, and organize your thoughts with a smooth corkboard interface!

## ✨ Features

* **🪵 Interactive Corkboard UI:** Realistic cork texture, custom fonts, tilted notes, and realistic shadows.
* **🖱️ Drag & Drop:** Move notes freely around the board with smooth pointer controls.
* **📌 Pinning Mechanism:** Lock important notes in place to prevent accidental movement.
* **🔍 Category Filtering & Search:** Organize notes into Work, School, Personal, Shopping, and Other categories, then search through them instantly.
* **🧹 Tidy Up Layout:** Automatically arrange all unpinned notes into an aligned grid.
* **🎨 Color Customization:** Choose custom colors for individual notes, with automatic text contrast adjustment.
* **📊 Live Board Analytics:** Track note count, character usage, active categories, pinned notes, and completed tasks in real time.
* **⌨️ Keyboard Shortcuts:** Use built-in shortcuts for a faster workflow.
* **💾 Local Persistence:** Your board saves automatically using `localStorage`, so your notes persist between sessions in the same browser.

## ⌨️ Keyboard Shortcuts

| Shortcut         | Action                         |
| ---------------- | ------------------------------ |
| `N` / `Ctrl + N` | Create a new sticky note       |
| `/` / `Ctrl + F` | Jump to the search bar         |
| `Ctrl + S`       | Force-save the board           |
| `Esc`            | Close the active note or modal |
| `Shift + Delete` | Delete the currently open note |

## 🚀 Quick Start

1. **Clone the repository:**

   ```bash
   git clone https://github.com/beekay12/sticky-notes-board.git
   ```

2. **Open the project:** Open `index.html` directly in any modern web browser.

No dependencies, installations, or build steps required!

## 🛠️ Tech Stack

* **HTML5 & CSS3** — Custom CSS variables, glassmorphism, and animations.
* **Vanilla JavaScript** — DOM manipulation, the Pointer Events API, and `localStorage`.
* **Google Fonts** — *Caveat* and *Hanken Grotesk*.
